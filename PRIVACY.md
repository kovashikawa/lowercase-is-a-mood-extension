# Privacy policy

Lowercase Is a Mood does not collect, transmit, sell, or share any data. It makes no network requests and has no analytics, accounts, or remote code.

## What is stored

When you use the toggle on a site, the extension saves one on/off value for that site's origin (for example `https://example.com`) in `chrome.storage.local`. This stays in your browser on your device. It is used only to apply your choice the next time you visit that site, and it is never read by anything else.

## What the extension does on pages

It adds or removes a CSS class on the page's root element so the browser displays text in lowercase. It does not read, copy, or change page text, form values, or page source.

## Your control

Removing the extension deletes its stored values. Chrome's own policies cover the install and update process, which the developer does not receive data from.
